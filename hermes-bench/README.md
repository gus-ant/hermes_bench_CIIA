# HERMES-BENCH App

Esta é a aplicação web e engine de execução do **HERMES-BENCH**, desenvolvida com Next.js 16 (App Router), TypeScript e MongoDB.

Para ler a documentação completa da plataforma, arquitetura, métricas e instruções de instalação, consulte o arquivo [README principal no repositório](file:///e:/hermes_bench_CIIA/README.md).

## Execução Rápida

```bash
# 1. Instalar dependências
npm install

# 2. Popular o banco com tarefas e modelos de teste
npm run seed

# 3. Iniciar o servidor em desenvolvimento
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.
